# Forty-five builds

Playable browser pages made with **Grok 4.7 high**.

Each page keeps a technique from [Top 15 Things built with Claude OPUS 5.5](https://www.youtube.com/watch?v=dw4rYWy8nLw) and changes the subject. The fifteen reference variations are [az9713/opus-5.5-builds](https://github.com/az9713/opus-5.5-builds), also playable at [az9713.github.io/opus-5.5-builds](https://az9713.github.io/opus-5.5-builds/). This repo is the next step: three subjects for each of those fifteen techniques, ninety pages in two passes.

## Play

The site is GitHub Pages. Start at the [project page](https://az9713.github.io/grok-4.7-builds/). The repo is [az9713/grok-4.7-builds](https://github.com/az9713/grok-4.7-builds).

- [Forty-five builds](builds-ns/) is the full set: lyric films, Blender heroes and clay time-lapses, sketchbooks, and the rest.
- [Earlier set](builds/) is the same subjects, built first.
- [Guide](guide.html) is how to use the skills.
- [Journey](journey.html) is how the forty-five pages were made.

Open a link. The pages are static, so they run on GitHub Pages without a server. Lyric studios load p5 from `vendor/`. The three later multiplayer scenes load Three.js from `vendor/three.module.js` and play as one person in the browser.

Two windows on one shared world still need the local server in that build’s README. Those ports are 3521, 3522, and 3523 for the earlier set, and 3531, 3532, and 3533 for the full set.
