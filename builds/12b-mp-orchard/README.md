# Dawn orchard

Two browser windows on this machine. No mouse-look, so both windows can be used at once.

```
npm install
npm start
```

Open http://127.0.0.1:3522/?name=ada and http://127.0.0.1:3522/?name=bo.

Walk with WASD or the arrow keys. Positions should match in under a second. The page shows the last state age in milliseconds. Chat is on the same socket.
